# Project instructions

- Target Omarchy Quattro on current Arch Linux and Wayland first.
- Keep the root `manifest.json` and `Plugin.qml` valid as an Omarchy plugin.
- Use Rust for game/domain logic and Slint for the native UI.
- Keep game rules deterministic, replayable, serializable, and independent of rendering.
- All card faces, backs, backgrounds, animation curves, sounds, icons, copy, and layouts must be original or clearly licensed for this repository.
- Do not copy or trace Microsoft Solitaire Collection assets or presentation.
- Add tests for every rule variant and commit/push coherent feature slices to `main`.
